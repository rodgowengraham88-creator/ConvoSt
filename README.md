# Starters

Conversation starters with ratings and notes, organised by category. Works offline; data is stored on the device.

Files: `index.html` (the whole app), `sw.js` (offline cache), `manifest.webmanifest`, `icons/`.

To publish an update: replace `index.html`, then bump `CACHE` in `sw.js` (e.g. `starters-v2`).
